# AutoAccept for LFG

Retail World of Warcraft addon that automatically accepts group invites and LFG role selection. It does nothing else.

## What it does

- Accepts incoming party and raid invites from anyone.
- Confirms LFG role-check popups using the roles already selected in Dungeon Finder.

## What it does not do

- Does not click Premade Group Finder invite dialogs (`C_LFGList.AcceptInvite` is hardware-protected).
- Does not auto-accept ready checks, dungeon/raid “Enter” popups, summons, or guild invites.
- Does not auto-apply to groups in Group Finder.

## Install

Copy this folder to:

`World of Warcraft/_retail_/Interface/AddOns/AutoAcceptforLFG/`

Restart the game or `/reload`.

## Config

There is none. The addon is always on while enabled.

Disable it from the in-game AddOns list (character select screen) to turn it off.
